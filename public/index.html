Vehicles

The fleet — CRUD with photo upload and soft delete.

GET /vehicles 🔒

List with pagination, category filter and name search.

?page?limit ?category?search
GET /vehicles/:id 🔒

Fetch a single vehicle. 404 if soft-deleted.

POST /vehicles 🔒

Create a vehicle. multipart/form-data with a photo.

multipartphoto 409 dup plate
PUT /vehicles/:id 🔒

Update fields; replace or clear the photo.

DELETE /vehicles/:id 🔒

Soft delete — sets deleted_at, keeps rental history.

📅

Rentals

Bookings — server-side pricing and a race-proof overlap check.

GET /rentals 🔒

List with vehicle, status and date-range filters + search.

?vehicle_id?status ?start_date?end_date
GET /rentals/:id 🔒

Fetch one rental, joined with its vehicle.

POST /rentals 🔒

Book a vehicle. total_amount is computed server-side; an overlapping active rental is rejected with 409 inside a transaction.

overlap-safe server-priced
PUT /rentals/:id 🔒

Edit a rental; date/vehicle changes re-run the overlap check.

DELETE /rentals/:id 🔒

Remove a rental.
